# LACVAY UI Design Prototype
## Retro Transit Poster Style

This folder contains the complete UI design prototype for **LACVAY**, a Philippine local transportation and tourism assistant for Batangas City.

### 🎨 Design Style: Mid-Century Travel Poster

The design draws inspiration from **vintage transit posters** of the golden age of travel — bold typography, vibrant color blocks, thick borders, and flat illustrations reminiscent of classic jeepney route boards and Philippine tourism campaigns.

---

## 📁 Files

- **`index.html`** — Complete interactive prototype featuring:
  - Navigation bar with retro bold typography
  - Hero section with gradient card showcasing Route Finder mockup
  - Six core feature cards (Route Finder, Fare Checker, Book a Ride, Drive Yourself, Tourism Guide, Nearby Eats)
  - AI Travel Assistant chat mockup with colorful chat bubbles
  - Business promotion CTA with vibrant gradient
  - Responsive footer

- **`styles.css`** — Full retro design system:
  - Vibrant "Vibrant Transit" color palette (cream, coral, gold, teal, navy, lime)
  - Retro typography with uppercase, bold condensed type
  - Thick borders (3–4px) with offset drop shadows (3px 3px 0px)
  - Gradient overlays on cards (coral→gold, teal→lime, etc.)
  - Retro button and pill styles
  - Mobile-responsive grid layouts

- **`DESIGN_SYSTEM.md`** — Complete design documentation:
  - Color palette reference table
  - Typography guidelines
  - Border and shadow specifications
  - Component styling guide
  - Visual hierarchy breakdown
  - Responsive breakpoints
  - Design inspiration sources

## 🎯 Key Features

### Retro Aesthetic Elements
✅ **Vibrant Palette**: Cream background with pops of coral, gold, teal, and lime  
✅ **Bold Typography**: Heavy, condensed sans-serif (Poppins 800–900) in ALL CAPS  
✅ **Thick Borders**: 3–4px navy borders on all cards and buttons  
✅ **Retro Shadows**: Classic offset drop shadows (3px 3px 0px)  
✅ **Gradient Cards**: Multi-color gradients mimicking vintage poster backgrounds  
✅ **Decorative Elements**: Stars, colored dots, and pill badges  
✅ **Route Board Style**: Input fields and stat boxes styled like vintage transit signage  

### Functional Sections
1. **Hero** — Introduces LACVAY with prominent CTA buttons and stat metrics
2. **Features** — 6 core app functions in a 3-column grid
3. **AI Assistant** — Interactive chat mockup with lime-to-teal gradient
4. **Business Promo** — CTA for local businesses to boost sales
5. **Navigation** — Sticky top navbar with uppercase links and retro styling

## 📱 Responsive Breakpoints

- **Desktop** (>900px): 2-column hero, 3-column feature grid
- **Tablet** (900px–560px): 1-column hero, 2-column feature grid
- **Mobile** (<560px): Full-width single column, scaled headlines

## 💡 Design Principles

1. **Local Connection**: The retro aesthetic directly ties to jeepneys, vintage route boards, and mid-century Philippine tourism culture
2. **Bold & Clear**: Heavy typography and thick borders ensure clarity on all screen sizes
3. **Vibrant Energy**: Saturated colors create excitement and approachability for diverse users (commuters, students, tourists)
4. **Functional Beauty**: Despite the retro style, maintains modern UX practices and whitespace discipline
5. **Beginner-Friendly**: Large touch targets, clear visual hierarchy, playful personality

## 📝 Design Notes

- The design intentionally avoids photo backgrounds — all cards use solid colors and gradients for a pure "poster" feel
- Typography is deliberately bold and uppercase to evoke vintage route boards and signage
- The cream background (#FFF8DC) provides warmth and nostalgia while maintaining contrast
- Stat boxes and pill badges use the full vibrant palette to create visual interest without clutter
